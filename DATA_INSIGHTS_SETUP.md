# Quick Setup Guide - AI Data Insights

## 🚀 Getting Started

Your new **AI Data Insights** feature is now live! Here's how to set it up and use it.

## Step 1: Configure Gemini API Key

### Get Your API Key
1. Visit: https://makersuite.google.com/app/apikey
2. Sign in with your Google account
3. Click "Create API Key"
4. Copy the generated key

### Add to Environment
Open your `.env` file and add:
```env
VITE_GEMINI_API_KEY=your_api_key_here
```

**Example:**
```env
VITE_GEMINI_API_KEY=AIzaSyABC123def456GHI789jkl012MNO345pqr
```

## Step 2: Restart Development Server

After adding the API key, restart your dev server:

```bash
# Stop the current server (Ctrl+C)
# Then restart:
npm run dev
```

## Step 3: Access the Feature

1. Log in to your ERP system
2. Look in the sidebar under **Analytics** group
3. Click on **"Data Insights"** (📊 icon)

## Step 4: Upload Your First File

### Supported Formats
- ✅ CSV (.csv)
- ✅ Excel (.xlsx)
- ✅ Excel Legacy (.xls)

### Try It Out
1. Click "Choose File" button
2. Select a CSV or Excel file
3. File info will appear (rows × columns)
4. Click "Analyze with Gemini AI"
5. Wait 3-10 seconds for results
6. View insights and visualizations!

## What You'll Get

### 📊 AI-Generated Insights
- **Summary**: Overview of your data
- **Key Findings**: 3 important discoveries
- **Recommendations**: 3 actionable suggestions
- **Visualizations**: 2-3 relevant charts

### 📈 Chart Types
- **Bar Charts**: Compare categories
- **Line Charts**: Show trends over time
- **Pie Charts**: Display proportions

## Troubleshooting

### "Gemini API key not configured"
**Solution**: Make sure you added `VITE_GEMINI_API_KEY` to `.env` and restarted the server

### File won't upload
**Solution**: Check that your file is .csv, .xlsx, or .xls format

### Analysis takes too long
**Solution**: This is normal for large files. Wait up to 15 seconds.

### Charts not showing
**Solution**: The AI might not have found suitable data for charts. Try a different file.

## Tips for Best Results

### ✅ Good Data Files
- Clear column headers
- Consistent data types
- No empty rows
- Numeric values for charts
- Date/time in standard format

### ❌ Avoid
- Files with merged cells
- Multiple tables in one sheet
- Heavily formatted Excel files
- Files with formulas only (no values)
- Extremely large files (>10MB)

### Common Questions

**Q: Is my data secure?**  
A: Yes! Only the first 10 rows are sent to Gemini for analysis. Files are processed locally.

**Q: How much does it cost?**  
A: Gemini API has a free tier. Check Google's pricing for details.

**Q: Can I analyze multiple files?**  
A: Currently one at a time. Clear and upload new for another analysis.

**Q: What's the file size limit?**  
A: Browser dependent, typically 50-100MB. Smaller files work better.

**Q: Can I customize the charts?**  
A: Not yet, but coming soon! Charts are auto-generated by AI.
